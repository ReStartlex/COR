# Игровые основы программирования — ЦОР

Цифровой образовательный ресурс (ЦОР) для школьников 5–8 классов по основам
программирования + портфолио его разработки по дисциплине «Разработка цифрового
образовательного контента».

**Автор:** Савчишен Алексей Алексеевич · ТГПУ им. Л. Н. Толстого, группа 1680151И.

## Что это

Проект состоит из двух связанных страниц:

| Страница | Что внутри |
|----------|------------|
| **`course.html`** | Сам **ЦОР** — витрина учебного курса: титульная информация, промо-ролик, полная аннотация, результаты обучения, система оценивания и полностью наполненный модуль «Циклы» (видеолекция, лекция, инфографика, тренажёры, самостоятельная работа и **интерактивный тест** с автопроверкой). |
| **`index.html`** | **Портфолио разработки** — все задания дисциплины (1.5–3.2) с ответами, анализом, медиа и интерактивом. Документирует процесс создания курса. |

Страницы перекрёстно связаны навигацией.

## Технологии

Чистые **HTML + CSS + JavaScript**, без тяжёлых фреймворков. Сайт **статический**:
его можно открыть как файлы или отдавать через Nginx без сборки и без Node-процесса.

## Структура проекта

```
.
├── index.html              # Портфолио разработки (задания 1.5–3.2)
├── course.html             # ЦОР — витрина учебного курса
├── 404.html                # Страница «не найдено»
├── robots.txt              # Для поисковых роботов
├── sitemap.xml             # Карта сайта
├── README.md               # Этот файл
├── DEPLOY.md               # Инструкция по публикации на VPS + домен
├── package.json            # Скрипты для локальной разработки (Vite, опционально)
├── vite.config.js          # Конфиг Vite (только для dev/preview, порт 3002)
├── .gitignore
├── assets/
│   ├── css/                # Стили, вынесенные из HTML
│   │   ├── base.css          # переменные, сброс, типографика
│   │   ├── layout.css        # навигация, hero, секции, сетка
│   │   ├── components.css    # карточки, вкладки, таблицы, медиа-блоки
│   │   ├── responsive.css    # адаптивные правила (@media)
│   │   ├── print.css         # печать и reduced-motion
│   │   └── course.css        # стили витрины курса
│   ├── js/                 # Скрипты, вынесенные из HTML (обычные, не модули)
│   │   ├── tabs.js           # раскрытие карточек и вкладки
│   │   ├── navigation.js     # тема, меню, scroll-spy, счётчики, «развернуть все»
│   │   ├── progress.js       # учёт прочитанного, прогресс, сброс, конфетти
│   │   ├── media.js          # видео-слоты, ARIA-вкладки, лайтбокс
│   │   └── course.js         # навигация, лайтбокс и тест витрины курса
│   ├── img/                # author.jpg, infogram1–3.png, favicon.svg, og-image.png
│   ├── video/              # video-animation.mp4, vidu.mp4, cikly-lecture.mp4*
│   └── docs/               # cikly_v1.pdf, cikly_v2.pdf (презентации)
└── source/                 # Исходные материалы дисциплины (не часть сайта)
    ├── teoria/               # теоретические материалы
    ├── zadania/              # тексты заданий
    ├── instructions/         # памятки по сборке медиа в сервисах
    └── NOTES.txt
```

> `course.js` отвечает за canvas-анимацию робота (живое демо цикла), переключение
> темы, reveal-анимации, счётчики, лайтбокс и интерактивный тест витрины курса.

\* `assets/video/cikly-lecture.mp4` (~114 МБ) не попадает в Git (лимит GitHub 100 МБ) —
загружается на сервер отдельно. См. **DEPLOY.md**.

> ⚠️ **Важно про порядок подключения.** Скрипты — обычные (не ES-модули), функции
> глобальны для inline-обработчиков. Порядок в `<head>`/`<body>` менять нельзя:
> CSS — base → layout → components → responsive → print;
> JS — tabs → navigation → progress → media.

## Локальный запуск

Самый простой способ — открыть `index.html` или `course.html` прямо в браузере.

Для удобной разработки с авто-перезагрузкой (необязательно):

```bash
npm install
npm run dev       # откроется на http://localhost:3002
```

Опциональная сборка: `npm run build` → папка `dist/`.
Для продакшена сборка **не требуется** — Nginx отдаёт файлы как есть (см. DEPLOY.md).
