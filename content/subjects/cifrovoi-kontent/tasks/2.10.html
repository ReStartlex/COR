Задание 1. Типы заданий и особенности оценивания

Я рассмотрел практические задания на MOOC-платформах (Stepik, Открытое образование, Coursera) и в «Российской электронной школе». Большинство заданий относится к закрытому или открытому типу с автоматической проверкой.

Тип заданияГде встречаетсяОсобенности оценивания
Выбор одного ответаStepik, РЭШ, Courseraавтопроверка, мгновенный результат
Множественный выборStepik, Открытое образованиеавтопроверка, учёт частично верных
Ввод ответа (число/слово)Stepik, РЭШсверка с эталоном, иногда несколько вариантов
Сопоставление / сортировкаStepik, РЭШавтопроверка по парам/порядку
Программные задачи (код)Stepikпроверка тестами, баллы за пройденные тесты
Peer-review (взаимная проверка)Coursera, Открытое образованиеоценка по рубрике другими слушателями

Общая особенность: задания дают мгновенную обратную связь, часто разрешают несколько попыток, а баллы суммируются в общий прогресс. Это соответствует дидактическому требованию «возможность анализа ошибок».

Задание 2. Возможности интерактивных сервисов

Я изучил пять сервисов для создания интерактивных заданий и определил, какие из них подходят для модуля «Циклы».

LA
LearningApps
Пазлы · соответствие · викторины
Большой набор шаблонов: «найди пару», «классификация», «скачки», кроссворд. Удобен для тренажёров по терминам и видам циклов. Бесплатный, встраивается по iframe.
learningapps.org
WW
WordWall
Игровые шаблоны
Яркие игровые шаблоны («колесо фортуны», «найди пару», «угадай») с переключением одного материала между играми. Хорош для мотивации школьников. Часть функций платная.
wordwall.net/ru
Уд
Удоба
H5P · бесплатно
Российский конструктор на основе H5P: интерактивное видео, перетаскивание, заполнение пропусков, тесты. Полностью бесплатен, без водяных знаков.
udoba.org
LW
Liveworksheets
Интерактивные рабочие листы
Превращает обычные рабочие листы в интерактивные с автопроверкой. Подходит для текстовых заданий с вводом ответа.
liveworksheets.com
КД
Квестодел
Образовательные квесты
Конструктор веб-квестов с цепочкой заданий и сюжетом. Подходит для геймифицированного закрепления темы целиком.
kvestodel.ru

Вывод: для модуля «Циклы» оптимальны LearningApps (тренажёры по понятиям), Удоба (бесплатные H5P-задания) и WordWall (игровая мотивация). Именно в них разработаны задания в пункте 2.11.
