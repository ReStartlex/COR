Задание 1. Тестовые задания по теме «Циклы»

Подготовлено 6 заданий разных типов на одну контрольную точку (трудоёмкость изучения темы ≈ 25 минут). Задания составлены по рекомендациям теории 2.12: одна мысль на вопрос, 4 варианта в закрытых заданиях, без отрицаний и подсказок, расположены по нарастанию сложности.

Вопрос 1выбор одного ответа

Что называют телом цикла?

  • команду остановки цикла

  • число повторений
  • условие выхода

Сколько раз выполнится команда «прыжок»?

повторить 7 раз: прыжок

Вопрос 3множественный выбор

Какие утверждения о циклах верны? (выберите все верные)

  • ✓ цикл помогает не писать одинаковые команды много раз
  • ✓ цикл со счётчиком повторяет действие заданное число раз
  • ✓ цикл с условием выполняется, пока условие истинно
  • цикл всегда выполняется ровно один раз
  • цикл не может содержать другие команды
Вопрос 4установление соответствия

Сопоставьте вид цикла и подходящую ситуацию.

  • Цикл со счётчиком → нарисовать квадрат (4 стороны)
  • Цикл с условием → идти вперёд, пока не появится стена
Вопрос 5установление последовательности

Расставьте этапы выполнения цикла с условием по порядку.

  1. проверка условия
  2. выполнение тела цикла (если условие истинно)
  3. возврат к проверке условия
  4. выход из цикла (если условие ложно)
Вопрос 6заполнение пропуска

Вставьте пропущенное слово (введите в именительном падеже):

«Если условие цикла никогда не станет ложным, возникает ________ цикл, и программа зависает.»

Ответ: бесконечный

В рамках курса этот тест используется как тест для самоконтроля по модулю. Итоговый тест по всей дисциплине формируется по той же методике (см. инструкцию в подзадании 3).

Задание 2. Система оценивания результатов обучения

Система оценивания оформлена по шаблону из методических указаний: раздел → категория (результат обучения) → компонент (задание) → число попыток → максимальный балл.

Показатели и критерии оценивания

  • Тренажёры и тест — оцениваются автоматически по доле верных ответов;
  • Мини-проект — по рубрике: корректность логики, использование циклов, самостоятельность, аккуратность, работоспособность.

Шкала оценивания (перевод процента в оценку)

Доля балловОценка
85–100%отлично (5)
70–84%хорошо (4)
55–69%удовлетворительно (3)
менее 55%не зачтено

Процедура и алгоритм расчёта итоговой оценки

Текущий контроль · 60%
Мини-проект · 40%

Итоговый балл рассчитывается по формуле:

Итог = 0,6 × (тренажёры + тест) + 0,4 × мини-проект

Баллы по каждому компоненту переводятся в проценты от максимума, складываются с учётом веса, затем по шкале определяется оценка. Курс считается пройденным при итоге ≥ 55%.

Система реализует принцип конструктивной согласованности: каждый результат обучения связан с заданием и способом проверки, а вес отражает значимость компонента.

Задание 3. Инструкция к итоговому тесту по курсу

Инструкция к итоговому тесту «Игровые основы программирования»

Уважаемый участник! Итоговый тест проверяет знания по всему курсу — от алгоритмов до циклов и мини-проекта.

  • Количество вопросов: 30 (по 5–6 на каждый модуль), выдаются в случайном порядке;
  • Время на выполнение: 40 минут;
  • Число попыток: 2, засчитывается лучший результат;
  • Типы заданий: выбор ответа, множественный выбор, соответствие, последовательность, заполнение пропуска;
  • Навигация: разрешён пропуск вопроса и возврат к нему до завершения теста;
  • Порог прохождения: 55% правильных ответов;
  • Оценка: выставляется автоматически по шкале из подзадания 2;
  • Рекомендация: перед началом повторите конспекты и пройдите тренажёры по модулям.

Параметры (число вопросов, время, попытки, порог) заданы по рекомендациям теории 2.12: время не более 45–90 минут, ключи и шкала фиксируются заранее.
