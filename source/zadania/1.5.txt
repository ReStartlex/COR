 Задание 2: Подберите коллекцию цифровых образовательных ресурсов (ЦОР) (не менее 10) по теме индивидуального проектного задания. В коллекцию включите следующие типы ресурсов:

ЦОР для объяснения нового материала: презентация, видео обучающее по теме (информационное), видео-лекция (информационное, говорящая голова), видео обучающее с анимацией, видео мастер-класс, анимация, ментальная карта по понятиям, по изучаемой теме, рабочие листы, текстовый вариант урока по новой теме для школьников, виртуальные музеи, виртуальные лаборатории

ЦОР для закрепления материала: тренажеры, игровые тренажеры (игры), карточки, викторины, интерактивные средства для доски и поверхностей, квесты, текстовые рабочие листы для школьников,

ЦОР для контроля: тесты, проверочные работы в тексте, контрольные работы в тексте.

Другие материалы: конспекты уроков, конспекты мероприятий, тематическое планирование, методические рекомендации, различные образовательные программы, электронные учебники, электронные курсы, рабочие программы
