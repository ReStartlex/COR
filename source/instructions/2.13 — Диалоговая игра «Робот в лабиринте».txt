================================================================
2.13 — ДИАЛОГОВАЯ ИГРА «РОБОТ В ЛАБИРИНТЕ»
================================================================

Сценарий игры готов (в index.html, задание 2.13). Нужно собрать ветвящуюся
игру в конструкторе. Гистограмма и анализ данных уже сделаны в сайте —
от тебя требуется ТОЛЬКО собрать игру.

Куда заходить (на выбор):
  • Удоба → H5P «Branching Scenario» (ветвящийся сценарий) — бесплатно:
    https://udoba.org
  • или Квестодел: https://kvestodel.ru/

Идея: робот идёт по лабиринту. На каждом шаге игрок выбирает команду.
Верно → идём дальше; неверно → подсказка и повтор.

Содержание шагов (КОПИРУЙ):

  ШАГ 1.
  Вопрос: «Впереди дорожка из 8 одинаковых клеток. Как заставить робота пройти её?»
    - 8 раз написать команду “шаг вперёд”           → неверно (долго, легко ошибиться)
    - Использовать цикл: “повторить 8 раз: шаг вперёд”  → ВЕРНО, идём дальше
    - Написать “шаг вперёд” один раз                → неверно

  ШАГ 2.
  Вопрос: «Робот не знает, сколько клеток до стены. Какой цикл выбрать?»
    - Цикл со счётчиком “повторить 5 раз”           → неверно
    - Цикл с условием: “пока впереди свободно — шаг вперёд”  → ВЕРНО
    - Совсем без цикла                              → неверно

  ШАГ 3 (ловушка).
  Вопрос: «Игрок написал “пока впереди свободно — поворот”. Что произойдёт?»
    - Бесконечный цикл: робот крутится на месте     → ВЕРНО (он не движется, стена не появляется)
    - Робот дойдёт до стены                         → неверно
    - Робот сделает один поворот и остановится      → неверно

Финал: «Лабиринт пройден! Ты понял, как работают циклы. 🎉»

Как собрать в Удобе (H5P Branching Scenario):
  1. Создать контент → выбрать «Branching Scenario».
  2. Добавить «Branching Question» для каждого шага (вопрос + варианты).
  3. К каждому варианту привязать переход: верный → следующий шаг,
     неверный → экран с подсказкой и возврат к этому же вопросу.
  4. В конце добавить финальный экран с поздравлением.
  5. Сохрани → возьми ссылку для встраивания.

Как вставить в сайт:
  Можно использовать слот id="embed-learningapps" (или добавить игру в курс
  на Tilda/Stepik как iframe). См. файл «00 — ГЛАВНОЕ».
