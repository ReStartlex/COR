2.11 — ИНТЕРАКТИВНЫЕ ЗАДАНИЯ. Перенос в сервисы
================================================================

Содержание всех заданий готово (в index.html, задание 2.11). Нужно собрать их
в сервисах и получить ссылки для встраивания. Ниже — что и куда вставлять.

Распределение по сервисам:
  Задание 1 (соответствие)        → LearningApps, шаблон «Найди пару»
  Задание 2 (подсчёт шагов)        → Удоба (H5P), «Заполни пропуск» / ввод ответа
  Задание 3 (последовательность)   → LearningApps, «Расставь по порядку»
  Задание 4 (поиск ошибки)         → WordWall, «Викторина»


----------------------------------------------------------------
ЗАДАНИЕ 1 — LearningApps «Найди пару» (соответствие)
----------------------------------------------------------------
Куда: https://learningapps.org → «Новое упражнение» → «Найти пару».
Пары (термин ↔ определение):
  Цикл            — команда, повторяющая действия несколько раз
  Тело цикла      — действия, которые повторяются
  Итерация        — один повтор тела цикла
  Счётчик         — число повторений в цикле со счётчиком


----------------------------------------------------------------
ЗАДАНИЕ 2 — Удоба «Заполни пропуск» (ввод ответа)
----------------------------------------------------------------
Куда: https://udoba.org → создать → H5P «Fill in the Blanks».
Текст задания:
  «Робот выполняет: повторить 5 раз [ шаг вперёд; шаг вперёд ].
   Сколько всего шагов вперёд он сделает? Ответ: *10*»
  (звёздочками в H5P отмечается правильный ответ)
Пояснение для ученика: в теле цикла две команды, цикл повторяется 5 раз → 5×2=10.


----------------------------------------------------------------
ЗАДАНИЕ 3 — LearningApps «Расставь по порядку» (последовательность)
----------------------------------------------------------------
Куда: https://learningapps.org → «Новое упражнение» → «Расположить по порядку».
Правильный порядок шагов выполнения цикла с условием:
  1. проверить условие
  2. если истинно — выполнить тело цикла
  3. вернуться к проверке условия
  4. если ложно — выйти из цикла


----------------------------------------------------------------
ЗАДАНИЕ 4 — WordWall «Викторина» (поиск ошибки)
----------------------------------------------------------------
Куда: https://wordwall.net/ru → «Создать занятие» → «Викторина».
Вопрос:
  «Робот должен нарисовать квадрат, но фигура не замыкается:
   повторить 3 раза [ вперёд; поворот направо на 90° ]. Где ошибка?»
Варианты:
  А. неверный угол поворота
  Б. цикл нужно повторить 4 раза, а не 3   ← ПРАВИЛЬНЫЙ
  В. команды стоят в неправильном порядке
  Г. ошибки нет


----------------------------------------------------------------
КАК ВСТАВИТЬ В САЙТ
----------------------------------------------------------------
  • В каждом сервисе после сохранения возьми «ссылку для встраивания»
    (Embed / iframe / «Поделиться»).
  • В index.html есть универсальный слот id="embed-learningapps" — вставь
    в его data-src ссылку одного из заданий (см. файл «00 — ГЛАВНОЕ»).
  • Остальные задания вставляются прямо в курс на Tilda/Stepik как блоки-iframe.
